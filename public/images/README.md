# Photos go here

Drop real classroom photos into this folder using the **exact filenames** below.
As soon as a file exists, the matching placeholder on the site is replaced
automatically — no code changes needed.

Use `.jpg` (or change the extension in the data file under `src/data/`).
Landscape shots at roughly **4:3** look best in the cards.
