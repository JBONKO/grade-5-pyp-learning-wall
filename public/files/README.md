# Downloadable files go here

The Resources page lists templates and routines. Each one expects a file in this
folder. Add a PDF with the matching name, then turn the card into a real
download (see the comment in `src/app/resources/page.tsx`).

Filenames the Resources page references:

- `pull-up-a-chair-routine.pdf`
- `research-unstuck-wall.pdf`
- `sticky-note-connection-system.pdf`
- `project-map-template.pdf`
- `presentation-station-design-map.pdf`
- `station-test-fix-list.pdf`
- `x-journal-homework.pdf`
- `mentor-meeting-expectations.pdf`
- `build-week-material-rules.pdf`

You can change any of these names in `src/data/resources.ts`.
